Product overview · LNS-MS-LNG

Description

The LineSig LNS-MS-LNG is a dedicated cryogenic skid-mounted tanker loading metering system for controlled and traceable transfer of liquefied natural gas. The architecture combines cryogenic Coriolis mass flow measurement, cryogenic pressure and temperature monitoring, batch/ESD control, controlled cooldown provisions, thermal relief for trapped liquid sections, cryogenic loading interfaces and vapour/BOG management according to the project loading philosophy.

LNS-MS-LNG is a cryogenic product configuration and is not an ambient-service skid with substituted materials. Final design requires project LNG composition, operating and design temperature/pressure, minimum design metal temperature, cooldown sequence, boil-off gas philosophy, loading-arm/ERC data, trapped-liquid thermal relief, thermal-movement analysis, insulation/vacuum-jacket philosophy and hazardous-area requirements.

Design

Key features

  • Cryogenic Coriolis mass flowmeter
  • Cryogenic-rated pressure and temperature transmitters
  • Fail-safe cryogenic control/batch/ESD valve arrangement, extended bonnet/stem where required
  • Dedicated BOG/vapour-return connection and isolation/control philosophy
  • Explosion-proof local controller or TAS-integrated controller
  • Cryogenic loading arm or hose with ERC/breakaway philosophy
  • Thermal relief valves on sections where cryogenic liquid can be blocked in
  • Supports, flexibility and insulation/vacuum-jacket philosophy — project-specific

Advantages

  • Cryogenic Coriolis suits direct mass measurement without a conventional atmospheric-liquid air eliminator
  • Batch controller coordinates preset quantity, cryogenic Coriolis totalisation and batch termination
  • Controlled cooldown establishes stable cryogenic conditions before custody/batch measurement
  • ESD, gas-detection, loading-arm/ERC and vapour/BOG permissives coordinate with the terminal LNG safety system

Design boundary: final LNG design requires project-specific cryogenic process data, BOG philosophy, hazardous-area classification, loading-arm/ERC data and thermal-stress analysis — no generic ambient-service pressure/temperature values should be carried into this model.

Scope of supply

Standard scope of supply

  • Fabricated structural skid base frame with lifting provision
  • Cryogenic manual isolation valve or actuated ESDV, as specified
  • Low-pressure-drop cryogenic strainer where specifically required
  • Cryogenic-rated pressure gauge and pressure transmitter
  • Cryogenic temperature element/transmitter for cooldown and transfer monitoring
  • Cryogenic Coriolis mass flowmeter — primary metering device
  • Cryogenic FCV/batch/ESD valve with fail-safe action, cryogenic check valve where required
  • Explosion-proof batch controller with local display, keypad, preset, totalisation and I/O
  • Local ESD pushbutton, bonding/static-ground permissive where required
  • Cryogenic insulation/vacuum jacketing per project thermal design
  • Dedicated BOG/vapour-return connection with cryogenic valves as required
  • Thermal relief valves for blocked-in liquid sections; gas-detection/ESD interface to terminal LNG safety system

Minimum batch permissive — typical

  • Valid product / order / batch selected
  • Cryogenic route and source system ready
  • Cooldown sequence complete or approved loading condition established
  • Meter, batch controller and cryogenic valve chain healthy
  • BOG/vapour-return system ready where required
  • Loading-arm/hose and ERC interface healthy; no active ESD, gas-detection trip or critical skid fault

Loading sequence

Typical LNG loading sequence

Cryogenic inlet isolation/ESDV → Cryogenic strainer where specifically required → Cryogenic pressure/temperature measurement → Cryogenic Coriolis mass flowmeter → Cryogenic FCV/batch/ESD valve → Isolation → Cryogenic loading arm or hose/ERC — with controlled cooldown/recirculation and BOG/vapour return provided as parallel connections where required. Blocked-in liquid sections are protected by thermal relief.

Where it's used

Typical applications

  • LNG satellite stations and terminals
  • LNG bunkering facilities and marine loading
  • Cryogenic transfer stations, small-scale LNG distribution
