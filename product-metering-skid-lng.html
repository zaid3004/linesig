Product overview · LNS-MS-LNG

Description

The LineSig LNS-MS-LNG is a dedicated cryogenic tanker-loading metering system for liquefied natural gas. The skid is designed around cryogenic Coriolis mass measurement together with LNG-compatible piping, valves, instrumentation, insulation, ESD interfaces and boil-off/vapour management provisions.

The design considers cryogenic operating temperature, cooldown procedure, thermal contraction, pipe flexibility, support loads, insulation, external heat ingress, boil-off gas generation, pressure balance, cryogenic valve design and emergency release. The metering skid is integrated into the wider LNG loading sequence rather than treated as a standalone meter spool. Typical product: liquefied natural gas and project-specific LNG compositions.

Design

Key features

  • Cryogenic Coriolis mass flowmeter
  • Cryogenic stainless-steel process piping and isolation valves
  • Cryogenic FCV / batch / ESD valves
  • Pressure transmitters and cryogenic temperature transmitters
  • Explosion-proof batch control
  • BOG/vapour-return connection
  • Loading-arm / hose / ERC interface
  • Gas-detection and ESD system interface; insulated or vacuum-jacketed piping option

Advantages

  • Direct LNG mass measurement
  • Cryogenic-specific engineering, integrated cooldown monitoring
  • Compact packaged construction, reduced field assembly
  • ESD/ERC integration, BOG/vapour-return compatibility, terminal automation ready

Design boundary: final LNG design requires project-specific cryogenic process data, BOG philosophy, hazardous-area classification, loading-arm/ERC data and thermal-stress analysis — no generic ambient-service pressure/temperature values should be carried into this model.

Loading sequence

Typical LNG loading sequence

System ready → Cryogenic cooldown → Stable liquid conditions → Batch start → Cryogenic Coriolis metering → Controlled transfer → Batch completion → Valve closure → Safe isolation. Where required, vapour/BOG return operates simultaneously.

Where it's used

Typical applications

  • LNG truck loading and unloading
  • LNG satellite stations and terminals
  • LNG bunkering facilities and marine loading
  • Cryogenic transfer stations, small-scale LNG distribution
