Overview

LineSig Multi-Channel Dosing Skids are modular additive and chemical injection systems designed to meter and inject multiple components accurately into a common process or loading stream. Each channel can be configured with dedicated metering, control, isolation, calibration and injection hardware, allowing the package to support fuel additives, dyes, performance improvers, blending components and process chemicals with recipe-based control, ratio management, batch synchronization and PLC/TAS integration for repeatable, traceable and automated dosing across terminal and process applications.

Key features

  • Modular design — channels added per project requirement
  • Dedicated metering, control, isolation and calibration per channel
  • Suitable for fuel additives, dyes, performance improvers and blending components
  • Recipe-based dosing with ratio management and batch synchronization
  • PLC / TAS integration for repeatable, traceable, automated operation

How it's configured

Channels are added per project, not fixed by model

Each dosing skid is built from individual channel modules rather than a single fixed design — the number and duty of channels is selected to match the additives, dyes or process chemicals your application requires.

  • Each channel has its own metering pump, isolation and calibration column
  • Channels can dose different chemicals at independent ratios in the same run
  • Typical duties: fuel additives, dyes, performance improvers, blending components
  • Recipe-based control synchronizes multiple channels to a common batch
  • Skid scales from a small number of channels to larger multi-product terminals
  • PLC/TAS integration for ratio management, batch sync and transaction logging
