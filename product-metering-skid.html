02 — Product overview

Description

The LineSig LNS-MS Series is a modular family of skid-mounted metering systems engineered for accurate, controlled and traceable tanker loading, unloading and custody-transfer applications.

The family is built around Coriolis mass flow measurement as the preferred metering technology, integrated with an explosion-proof batch controller, flow regulation, process instrumentation, tanker grounding, overfill protection, ESD interfaces and terminal automation.

Rather than applying one generic metering package to every fluid, LNS-MS uses a service-specific engineering approach for refined liquid hydrocarbons, fuel oils and high-viscosity base/lube oils, pressurised LPG, and cryogenic LNG — so the skid configuration, metallurgy, pressure class, flow-control philosophy and safety architecture are selected against the actual product and operating conditions.

Typical process sequence

Product inlet → Isolation valve → Strainer / filter → Air/gas management where applicable → Pressure / temperature measurement → Coriolis mass flowmeter → Flow / batch control valve → Isolation / check valve → Loading arm or hose → Tanker. The exact sequence is adapted by service — atmospheric hydrocarbons may use an air eliminator, high-viscosity oils may need heating and tracing, LPG may require vapour-return/equalisation, and LNG requires cryogenic equipment, cooldown and BOG management.

03 — Design

Common LNS-MS advantages

  • Skid-mounted, factory-integrated construction
  • Coriolis mass flowmeter based measurement
  • Direct mass measurement, high repeatability
  • Explosion-proof batch controller
  • Preset quantity loading, automatic batch termination
  • Flow-control / batch valve
  • Pressure and temperature monitoring where required
  • Tanker static-grounding interface
  • Overfill protection interface
  • Emergency shutdown interface
  • Loading arm / hose integration
  • TAS / PLC / SCADA connectivity
  • Transaction and batch data logging
  • Factory assembly and pre-testing; reduced field installation

Custom engineering options

  • Single or duplex filtration
  • Proving / calibration connections
  • Additive injection, product sampling
  • Density measurement, temperature compensation

  • Vapour recovery / equalisation
  • Heating, tracing, insulation, recirculation

  • Printer, RFID, remote I/O
  • Skid canopy, stainless-steel construction, custom hazardous-area certification

04 — Control & safety

Batch control & terminal automation

Every LNS-MS skid is designed as a transaction system, not just a meter spool — the local batch controller and safety permissives coordinate with TAS/PLC/SCADA for order validation, transaction reporting and loading safety.

  • Preset batch entry, live flow indication
  • Delivered / target quantity, batch countdown
  • Start / stop command, FCV control
  • Mass totalisation, product selection
  • Alarm indication, transaction recording
  • Operator identification, RFID/card interface
  • Tanker ground verification and continuous monitoring
  • Automatic loading inhibit / shutdown on loss of ground
  • Independent tanker overfill input
  • ESD logic and local status indication
  • PLC / SCADA / DCS / Terminal Automation System interface
  • Historian, ERP, dispatch and vehicle-identification integration
