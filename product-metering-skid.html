Metering skid

A skid-mounted metering package built for accurate, repeatable custody-transfer flow measurement.

Overview

LineSig metering skids combine flow meters, valves, strainers and control instrumentation into a single pre-tested, pre-piped unit — reducing site installation time and giving you a fully documented package from day one.

Key features

  • Positive-displacement, turbine or ultrasonic meter options
  • Pre-piped, pre-wired and factory tested as one unit
  • Meter prover connections available
  • Full instrumentation and control package
  • Compact footprint for constrained sites
