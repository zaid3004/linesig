Metering skid — Pressurised LPG

LPG metering skid LNS-MS-LPG

A pressurised-liquid metering skid designed for safe and accurate loading of liquefied petroleum gas, keeping product in the liquid phase throughout the metering and control train.

Product overview · LNS-MS-LPG

Description

The LineSig LNS-MS-LPG is a modular skid-mounted tanker loading metering system developed for controlled and traceable transfer of liquefied petroleum gas from terminal storage or transfer headers to road, rail or marine loading interfaces. The standard architecture is based on Coriolis mass flow measurement together with local explosion-proof batch control, flow regulation, pressure monitoring, static grounding, pressure/temperature transmission and other loading safety interfaces.

For LPG service, the configuration emphasises accurate batch measurement, clean flow conditioning and loading safety, with a hydraulic design that maintains adequate liquid pressure through the skid to prevent flashing. Final size, flow range, pressure class, materials, meter model, batch controller certification and loading interface are selected against the actual project datasheet and hazardous-area requirements — Coriolis is preferred, not automatically mandatory.

Design

Key features

  • Coriolis mass flowmeter suitable for pressurised LPG
  • Hydraulic design maintains adequate liquid pressure through the skid to prevent flashing
  • Dedicated vapour return / equalisation interface where required
  • Product-specific strainer/filter
  • Pneumatic or electro-pneumatic flow/batch control valve
  • Explosion-proof local controller or TAS-integrated controller
  • Fail-safe ESD isolation and batch shutdown philosophy
  • Breakaway/ERC available at loading interface where required

Standard process sequence

Inlet isolation → Strainer/filter → Air eliminator or gas separator where applicable → Pressure/temperature measurement → Coriolis mass flowmeter → FCV/batch control valve → Check/isolation → Loading arm or hose interface, with vapour recovery where applicable.

Scope of supply

Standard scope of supply

  • Fabricated structural skid base frame with lifting provision
  • Inlet isolation valve — manual or actuated
  • Strainer/filter — basket, duplex or product-specific
  • DP indication across filter where required
  • Air eliminator / gas separator where applicable
  • Pressure gauge and pressure transmitter
  • Temperature element/transmitter where required
  • Coriolis mass flowmeter — primary metering device
  • Flow control / batch valve, check valve where required
  • Explosion-proof batch controller with local display, keypad, preset and I/O
  • Local ESD pushbutton
  • Tanker static-grounding interface, independent overfill interface
  • Junction / marshalling box
  • Loading arm / hose interface provision

Minimum batch permissive — typical

  • Valid product / order / batch selected
  • Correct product route available and transfer pump ready
  • Grounding status healthy for road tanker loading
  • Overfill protection interface healthy where provided
  • Meter and batch controller healthy
  • FCV / batch valve in correct initial position
  • No active ESD or critical skid fault
  • Loading arm / hose connection permissive where instrumented

Trip/shutdown — typical: ESD command closes the batch/ESD valve and stops pump demand; grounding loss during tanker loading triggers controlled or immediate shutdown per project safety philosophy; overfill trip stops the batch and closes transfer valve(s).
