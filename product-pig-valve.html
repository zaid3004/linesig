Pig valve LNS-PW

03 — Product overview · Model LNS-PW

Description

LINESIG Pigging Valves are purpose-designed multi-port pipeline valves for controlled routing of pipeline flow and pigs between a common line and selected branch connections. They provide a compact alternative to conventional pigging manifolds by combining isolation, directional flow control and pig-routing functionality within a single valve assembly.

The LINESIG LNS-WPV series is engineered for pipeline pig launching, receiving, bypass, transfer and routing applications in oil, gas, refined-product and process pipeline systems.

How it works

Operating principle

The internal valve element is rotated by the gear operator or actuator to align the selected internal flow passage with the required pipeline connections.

During pigging operation, the valve provides a continuous piggable passage between the selected ports, allowing the pig to travel through the valve without entering an unintended branch. Changing valve position redirects the pipeline flow and pig path to another selected connection.

Operation options

  • Manual gear operation — Heavy-duty gearbox and handwheel for local manual positioning.
  • Electric actuation — Suitable for remote operation, SCADA integration and automated pigging sequences.
  • Pneumatic actuation — Suitable for fast remote positioning where instrument air is available.
  • Hydraulic actuation — Suitable for large sizes, high operating torque and remote pipeline installations.
